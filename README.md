<h1 align="center">⭐ React Star Rating</h1>

<p align="center">
An interactive Star Rating component built with <strong>React</strong> that allows users to rate their experience, view instant feedback, and receive a confirmation modal after submission.
</p>

---

## ✨ Features

- ⭐ Interactive 5-star rating
- 🖱️ Hover preview effect
- 💬 Dynamic feedback messages
- ✅ Submit button validation
- 🎉 Confirmation modal
- 🔄 Reset rating after closing the modal
- 📱 Responsive UI

---

- React

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/your-username/react-star-rating.git
```

### Install Dependencies

```bash
npm install
```

### Run the Application

```bash
npm run dev
```

---

## 📸 How It Works

1. Hover over the stars to preview your rating.
2. Click a star to select a rating.
3. A feedback message is displayed.
4. Click **Submit** to open the confirmation modal.
5. Close the modal to reset the rating.
